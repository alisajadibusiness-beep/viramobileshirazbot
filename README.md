# VIRA MOBILE

Professional online mobile store platform.

## Features

VIRA MOBILE is designed as a centralized platform for:

- Mobile phone sales
- Product catalog
- Product variants
- Inventory management
- IMEI management
- Customer management
- Orders
- Favorites
- Price alerts
- Price history
- Telegram Bot
- Smart product recommendations
- Product comparison
- Trade-in
- Installment sales
- CRM
- Admin dashboard
- Website storefront
- Future WhatsApp integration
- Future Instagram integration

## Technology

- Python 3.12
- FastAPI
- SQLAlchemy
- PostgreSQL
- SQLite for local development
- aiogram
- Uvicorn
- Pydantic
